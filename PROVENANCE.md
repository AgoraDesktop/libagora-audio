# Provenance — libagora-audio

**Written for Agora, against macOS 10.12's Core Audio as a specification — not extracted from anywhere,
and not vendored.**

## What that means, precisely

Agora reproduces Apple's APIs so that a Cocoa application compiles and runs without being rewritten. Every
component in this tree does that: `libagora-core` reimplements Core Foundation's declarations,
`libagora-drawing` Core Graphics', `libagora-app` AppKit's. The declarations are written here; the
behaviour is ours; the names, types, constants and layouts are Apple's, because that is what the API *is*.

`libagora-audio` does the same thing with three differences, all of them about evidence rather than about
permission:

1. **The target version is stated and pinned.** macOS 10.12 — `MacOSX10.12.sdk`. Not "modern macOS", not
   "whatever the last machine had". A version is what makes "identical" a claim someone can check.
2. **The facts are measured from the reference and committed.** `tests/api/manifest-10.12.txt` is
   generated by `tools/api-manifest.py` from the reference headers: every record's size, alignment and
   field offsets; every enumeration constant's value; every typedef; every function's qualified type.
   `clang -fdump-record-layouts-complete` and `-ast-dump=json` produce them — we do not remember them, and
   two of the numbers in this repository would have been wrong if we had.
3. **The claim is tested, not asserted.** `tests/api/layout.c`, `tests/api/macros.c` and
   `tests/api/compile-cxx.cpp` fail on any drift. A size that changes without the manifest changing is a
   build failure, which is the only way a promise like this survives a year of edits.

## What is NOT in this repository

- **No Apple header text.** The SDK is never committed; the manifest is measurements of it. When the
  generator runs it reads the SDK in place and stages a scratch copy (to spell Darwin's `__nonnull` the way
  clang spells it everywhere) which is deleted when it finishes.
- **No Apple binary.** No `.dylib`, no framework, no extracted table.
- **No vendored audio code.** PipeWire, ALSA and sndio are found as *system* libraries by `pkg-config` when
  their phase arrives, and they are `PRIVATE` links: no type from any of them appears in a public header.

## `tools/refshim/`

Sixty lines of ours — `TargetConditionals.h`, `Availability.h`, an empty `MacTypes.h`, Core Foundation's
*types* only, dispatch's *types* only, and two `mach` stubs — which exist so the generator can run on
Linux, where a Mac is not required to read a header. They are not part of the library, are never
installed, and are not Apple's code: each file says so at its top.

The one thing a shim cannot fix is that Darwin's `__nonnull` is glibc's *function attribute* macro of the
same name, so the generator rewrites that spelling in its scratch copy. That is a fact about libc, not a
technique for getting around a licence.

## Behaviour: what is measured, and what is not

The API is checked mechanically. **Behaviour is not**: there is no macOS here to run a differential test
against, so the implementations follow the semantics the headers document, and each behavioural test names
the sentence it checks. `README.md` says which suites exist and what each measures; the plan
(`../AUDIO-PLAN.md` §1.3) says which doors are implemented, which refuse, and why a refusal is a better
answer than an absence.
